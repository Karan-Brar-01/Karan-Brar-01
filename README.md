## Engineering projects

- **[Distributed Ticketing System](https://github.com/Karan-Brar-01/distributed-ticketing-system)** — A solo ticket-reservation project using Redis Lua seat holds, PostgreSQL transactions and a partial unique index, RabbitMQ notifications, and Docker/Nginx. Includes integration tests for competing reservations and repeated confirmations. Payments are simulated; the previous EC2 deployment is intentionally stopped.
- **[RouteRelay](https://github.com/Karan-Brar-01/RouteRelay)** — A peer-to-peer delivery marketplace built with Next.js and Supabase/PostGIS. Includes route-matching code, transactional order transitions, version checks, and a QR/HMAC delivery-verification flow. Escrow is simulated.
- **[ClinicalPulse](https://github.com/Karan-Brar-01/ClinicalPulse)** — A Next.js/FastAPI health-assessment research prototype combining signal processing, structured APIs, database persistence, and patient/clinician workflows. Informally tried by classmates; not clinically validated.
- **[GROUNDTRUTH](https://github.com/Karan-Brar-01/groundtruth)** — An explainable procurement review prototype separating Python batch analytics from a Next.js interface and PostgreSQL/PostGIS data model. Uses deterministic synthetic fixtures and automated web/analytics tests.
- **[DSA Visualizer](https://github.com/Karan-Brar-01/dsa-visualizer)** — Interactive linked lists, trees, graph traversals, and sorting, with TypeScript algorithm engines separated from Zustand state and React Flow rendering.
- **[Autonomous Data Analytics Swarm](https://github.com/Karan-Brar-01/Autonomous-Data-Analytics-Swarm)** — A FastAPI/LangGraph analytics prototype with WebSocket progress, Docker-based execution of generated Python, and PostgreSQL run records.
